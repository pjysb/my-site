AI 协作 · 炫技展示

📝

提示词工程

把「自我介绍」拆解为身份、经历、技能、规划等多维需求，用结构化提示词让 AI 逐字还原档案原文。

prompt-engineering
🗂️

信息架构

将原始档案重新组织为「基础档案 / 成长高光 / 作品陈列 / 试炼 / 技能 / 规划 / 彩蛋」的可导航结构。

information-architecture
✨

动效生成

滚动渐显、时间线生长、数字跳动、打字机效果，全部由 CSS + 少量原生 JS 生成，零外部依赖。

motion-generation
⌨️

代码生成

单文件 HTML + CSS + JS，桌面与移动端响应式，深色底 + 青绿电光蓝渐变、玻璃拟态卡片与网格背景。

code-generation
♿

可访问性检查

语义化标签、键盘可操作、焦点可见、对比度达标，并适配 prefers-reduced-motion 减少动效。

accessibility
